## Phase 1 — Mid-term (EV retail, Excel)

**Funnel:** Lead Generation → Pre-Booking → Booking → Delivery  

**Sample KPIs (from analysis):**

| Metric | Value |
|--------|--------|
| Conversion (delivered / leads) | **72.9%** |
| Cancellation rate | **27.1%** |
| Avg TAT (lead → delivery) | **10.6 days** |
| NPS | **−53.5** |
